# Domain docs

采用 single-context，共享旅行地图领域术语和架构决策。

## 阅读规则

探索代码前，阅读根目录 GLOSSARY.md，以及 docs/adr/ 中与任务相关的 ADR。
文件尚不存在时继续工作，由 domain-modeling 在实际明确术语或决策时按需创建。

## 目录布局

- GLOSSARY.md：项目统一领域词汇表。
- docs/adr/NNNN-简短主题.md：架构决策记录，按编号递增。

## 使用规则

Issue、设计方案、代码及测试命名使用词汇表中的领域术语。
遇到尚未收录的概念时，先核对项目现有用语，再判断是否补充词汇表。
方案与已有 ADR 冲突时，指出对应 ADR、冲突内容和重新讨论的理由。
