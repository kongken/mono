# 功能描述

## 产品与使用流程

山海足迹帮助用户用颜色记录在中国走过的地方。用户在全国地图选择省级区域，进入省内地图，点击城市或区县即可自动配色并标记去过，再次点击取消；需要时另行编辑旅行日期与备注。

当前数据覆盖 34 个省级区域和 497 个城市、自治州、县市或区县。本文中的“城市足迹”统称这些可记录区域；全国城市统计合并直辖市及港澳的区县后，共 391 个统计目的地。数据范围见 [数据与地图说明](data-and-maps.md)。

## 全国与省内地图

- 海南省内主图聚焦海南本岛，三沙使用独立岛屿附图，整个附图可点选，两个视图保留同一套区域 ID 和标记规则；本岛的黎族及黎族苗族自治县地图标签使用简称，列表仍显示完整名称。开启 OSM 后初始视野同样聚焦海南本岛，可拖动至远海岛屿。
- 初始打开全国地图；点击地图轮廓或目的地列表进入对应省内地图。
- 全国地图下方提供北京、天津、香港、澳门“快速进入”按钮，解决小区域轮廓难以点选的问题；按钮显示与全国地图一致的探索颜色，点击或键盘 Enter / 空格进入对应区域，点击入口本身不会标记足迹。按钮高度至少 44px，窄屏采用两列布局，不受地图缩放影响。
- 普通省份展示城市、自治州等下一级区域，直辖市及港澳展示区县，台湾展示县市。金门县及连江县（马祖）在福建展示和记录；福建共 11 个可记录区域，台湾共 20 个。
- 全国地图中，存在省份独立标记或任意城市足迹的省级区域都会着色。
- 省内地图只按城市足迹着色；单独标记省份不会把省内全部城市标为去过。
- 全国地图、全国目的地列表与全国分享图片统一自动配色：根据本地全国地图的共同边界，预先为全部 34 个省份分配绿、黄、橙、蓝、紫；有共同边界的省份使用不同颜色，无共同边界的省份可以复用颜色，在满足相邻不同色的前提下尽量均衡使用五色。显示颜色独立于保存的城市及省份标记颜色，旧备份导入后同样生效，不修改已有记录。编辑城市、调整记录顺序、导入、新增或移除已探索省份均不会改变其他省份的颜色；未探索省份仍显示灰色。
- 点击省内区域或城市列表主按钮直接切换去过状态，不弹出编辑窗口；键盘 Enter 或空格执行相同切换。
- 已去过的城市列表行显示铅笔编辑入口，打开弹窗回填原记录。
- “中国”面包屑、返回按钮或品牌入口可回到全国地图。切换地图会清空搜索、重置缩放并回到地图标签页。
- 地图支持放大、缩小和重置；当前为以中心缩放，不支持拖动平移。地图加载失败时提供重新加载按钮。
- 省内地图右上角提供“OSM 底图”开关，默认关闭。开启后该省改用 OpenStreetMap 瓦片底图，行政区域叠加在底图上，支持滚轮或按钮缩放、拖动平移，以及“回到全省视图”按钮；底图经过淡化处理以突出区域颜色和名称，左上角仅保留返回按钮与标题；点击、键盘 Enter 或空格切换去过状态的规则不变。全国地图不受影响，始终使用本地绘制。开关偏好保存在当前浏览器，再次进入省内地图时沿用。
- 开启底图后浏览器会向 `tile.openstreetmap.org` 请求瓦片，页面角落显示 OpenStreetMap 署名；底图加载失败时提示可关闭底图，区域标记仍可使用。关闭开关即恢复原有 SVG 地图和中心缩放。

## 省份独立标记

省内页面提供“标记去过此省”和“取消省份标记”。新增独立标记保存的颜色优先沿用该省已有独立标记或第一条城市足迹的颜色；尚未探索的省份自动选择全国已探索省份的记录代表色中使用次数最少的颜色，同次数时按调色板顺序选择，适用于只想记录去过该省、尚未补全城市的情况。

独立标记与城市足迹相互独立：取消独立标记会保留城市记录；如果仍有城市足迹，全国地图中的该省仍算已探索。

## 城市足迹

地图和目的地列表支持一键标记与取消。本省第一条城市足迹沿用该省独立标记颜色；没有独立标记时，自动选择全国已探索省份的记录代表色中使用次数最少的颜色。后续新增足迹自动使用本省现有足迹中使用次数最少的颜色，并默认当天日期和空备注；使用次数相同时按调色板顺序选择，已有城市的颜色保持不变。

取消会移除该城市的足迹，包括日期与备注；提示出现期间可点“撤销”恢复完整记录。撤销入口仅针对最近一次取消，其他操作提示或提示自动消失后不可用。

可从已标记城市旁的铅笔按钮、“添加足迹”、收藏卡片或最近足迹进入编辑弹窗。

| 字段 | 当前规则 |
| --- | --- |
| 省份 | 可从全部省级区域中选择；改变省份会清空城市和备注，重置颜色与日期 |
| 城市 / 区县 | 必须选择，候选项随省份变化 |
| 颜色 | 默认自动选择山野绿、日落黄、珊瑚橙、海岸蓝或暮光紫，可手动调整 |
| 旅行日期 | 新增默认当前浏览器本地日期，可修改或留空 |
| 旅行记忆 | 选填，最多 1000 字符，保存时去除首尾空白 |

每个区域 ID 只保存一条足迹。再次保存已有城市会更新原记录，不会增加足迹数量；目前不能为同一城市记录多次独立旅行。

已有足迹可通过“移除足迹”删除。删除后，该城市恢复未探索状态，收藏和统计同步变化；若该省没有其他城市足迹和独立标记，全国地图中的省份也恢复未探索。

## 搜索与足迹查看

- 全国搜索匹配省份名称或省内城市名称，展示匹配的省份；例如搜索“杭州”会显示浙江。
- 省内搜索匹配当前省份下的区域名称。搜索使用名称包含匹配，暂不支持拼音或模糊纠错。
- 搜索可清空，没有匹配结果时显示提示。
- “旅行足迹”标签页展示城市足迹卡片，按日期降序排列。当前选中省份时，只展示该省足迹。
- “查看全部”清除省份筛选并切换到收藏视图。
- 最近足迹展示全局按日期降序排列的前 4 条记录；空日期排在有日期的记录之后。点击卡片可以编辑。
- 尚无足迹时提供空状态及添加第一站入口。

## 统计口径

| 指标 | 计算方式 |
| --- | --- |
| 已探索省份 | 省份独立标记的 ID 与城市足迹所属省份 ID 的去重并集 |
| 已打卡城市 | 全国按目的地去重：北京、天津、上海、重庆、香港、澳门各自有任一区县足迹即计 1 座，其余区域按区域 ID 计数；不包含独立省份标记 |
| 全国城市打卡率 | 上述去重城市数量 / 同口径目的地总数（当前 391），保留一位小数 |
| 中国探索度 | 已探索省份数量 / 34，四舍五入为整数百分比 |
| 省内已走过数量与打卡率 | 当前省份城市足迹数量 / 该省可记录区域总数；百分比保留一位小数 |

## 足迹统计与分享图片

- “足迹统计 / 生成图片”入口打开统计弹窗，展示全国已探索省份数量与比例、全国城市打卡数量与比例，以及有城市足迹的省份进度，按省内打卡率降序排列。
- 全国城市包含地图中的自治州、县市等目的地，直辖市及港澳分别最多计 1 座，分子和分母使用相同合并口径；首页、统计弹窗及全国分享图片一致。省内进度和省内分享图片仍按实际城市或区县区域统计，旅行足迹列表仍显示全部记录。独立省份标记只影响省份统计，不增加城市数量。标记、取消、撤销及导入后统计同步更新，搜索不影响统计。
- 弹窗预览当前全国或省内地图的分享卡片；全国卡片展示全国城市数量与打卡率，省内卡片展示该省数量与打卡率，两者均展示全国已探索省份数量。
- “生成并下载 PNG 图片”在浏览器内生成 1800 × 2000 的图片，包含本地行政区域地图、标记颜色、统计和生成日期；不包含旅行备注和 OSM 瓦片，不受地图缩放或搜索影响，无需第三方服务。
- 生成后提供图片链接，手机可打开后长按保存；生成失败显示重试提示。没有足迹也可生成空地图，地图未加载成功时下载按钮禁用。
- 图片用于分享，不替代 JSON 备份，无法通过图片恢复足迹。

## 保存与备份

每次足迹或独立省份标记变化后自动保存到当前浏览器。刷新或重新打开同一网站来源后恢复记录；页面选中的省份、搜索和缩放不会持久化。

旧缓存、账号缓存及备份中，金门县或连江县（马祖）仍归台湾的记录会在读取时自动改归福建，保留区域 ID、颜色、日期和备注；独立台湾省份标记保持不变。仅这两类已知旧记录适用迁移，其余无效记录仍触发校验保护。

导出会下载带有日期的 JSON 备份。导入会校验文件并显示记录数量，用户确认后替换当前全部足迹和独立省份标记；确认前可导出当前数据。无效文件只显示错误提示，不替换记录。文件限制、格式及兼容性见 [数据与地图说明](data-and-maps.md)。

保存失败时显示提示与导出入口。数据暂不跨浏览器或设备同步，清除网站存储会移除本地记录。

### 本地数据读取失败保护（F0）

启动时本地缓存存在但无法读取（JSON 损坏或被截断、结构版本不是 1、记录未通过校验）时，页面不会回落为空数据并保存，而是：

- 弹出不可关闭的“本地足迹数据无法读取”窗口，说明原因，并暂停自动保存；浏览器中的原始缓存保持不变。
- “导出原始数据”下载原始字符串（`山海足迹-原始数据-日期.json`），可多次导出。
- “恢复可识别的记录”仅在内容是版本 1 且至少有一条有效记录时出现，显示可识别及将丢弃的足迹、省份标记数量；确认后只保留通过校验的记录（重复城市保留第一条）。
- “以空数据开始”需再次点击确认；确认后以空数据继续。
- 恢复或以空数据开始前，原始数据会复制到浏览器中的 `shanhai-travel-v1-unreadable-<时间戳>`；若浏览器拒绝写入（如空间已满），需先导出原始数据才能继续。
- 缓存不存在或为空字符串属于正常的首次使用，不触发该保护；浏览器禁用存储时仍按保存失败提示处理。

## 账号与云端同步

仅当构建时设置了 `VITE_API_BASE_URL`（见 [后端初始化](backend.md)）才出现，未设置时界面没有任何登录入口，应用保持纯本地模式。登录可选，不登录的行为完全不变。

**登录与注册。** 页眉“登录”按钮（手机上为圆形图标）打开登录弹窗：用户名 + 密码登录，或切换到“注册”创建账号（用户名 3–32 位小写字母、数字、下划线，密码至少 8 位，昵称选填）；服务端配置了 GitHub、Google 时，弹窗下方显示对应按钮，点击后跳转第三方授权，回到 `/auth/callback/<provider>` 后完成登录。回调时必须与本浏览器发起的授权（保存在 `sessionStorage` 的 provider 与 state）一致，且只能使用一次，否则提示“登录请求无效或已过期”；回调地址里的授权码在请求前就从地址栏移除。错误提示一律为中文。

**登录后的数据。** 登录后页面显示并编辑该账号的云端足迹，本机登录前保存的本地足迹不显示，也不会上传或合并（迁移是 F2，待实现）；账号弹窗会提示本机仍有多少条本地足迹。每次编辑先把目标数据及服务端确认的祖先副本一起保存到本机账号缓存，再立即显示并后台按最多 100 项的原子批次发送；本机写入失败时拒绝此次编辑并提示导出备份。全部发送成功后显示“已同步到云端”，发送失败不回滚或丢弃修改，显示“本机已保存，待同步”。页面重新可见、网络恢复或点击重试时自动尝试同步。

**并发冲突。** 初次登录读取云端快照，随后读取带删除标记的有序增量；历史不足时重新取完整快照。同步，将本机尚未同步的差异与其他设备修改做三方合并；不同城市或省份标记自动合并，同一条记录双方改成相同内容也自动合并。同一记录不同修改（含一方删除）暂停写入，弹窗列出冲突区域，用户选择所有冲突记录“以本机为准”或“以云端为准”，不影响其他记录；可先导出本机足迹。每批写入携带精确 revision（包括 0）与持久化请求 ID；丢失响应后重放同一请求，不重复提交或反转标记；并发版本变化时重新读取并检查，连续竞争最多自动重试三次，之后保留修改供手动重试。旅行日期不用于判断修改先后。

**启动与离线。** 恢复登录时先用本机缓存的云端副本显示，同时向云端拉取；没有缓存则显示“正在加载云端足迹…”。有可校验的账号缓存时，即使离线仍可标记、编辑、删除、撤销和导出；未同步修改跨刷新保留，联网后重试同步。没有缓存且拉取失败时显示全屏错误，不接受编辑。账号缓存无法解析或校验失败时保留原始字符串并阻止读写覆盖，提供“导出原始账号缓存并退出”；下载触发后退出会明确清除该账号缓存。浏览器拒绝保存时暂停编辑，当前内存足迹仍可导出。

**登录期间的限制。** 导入备份被禁用（整体替换会产生大量写入，待 F2 一并设计）；导出备份仍可用，导出的是当前账号在页面上的足迹（包含未同步修改）。云端缓存存放在 `shanhai-cloud-v1:<用户 ID>`，登录会话在 `shanhai-session-v1`；本地模式的 `shanhai-travel-v1` 在登录期间不被读写。

**会话与退出。** 账号弹窗（点击头像）显示昵称、同步状态、本机残留的本地足迹提示，以及已登录设备列表，可退出其他设备。“退出登录”需二次确认，会先等待在途写入完成，再撤销本次会话，并清除本账号缓存与会话，随后回到本机的本地足迹；确认文字明确提醒：尚未同步修改会被丢弃，应先导出备份。撤销请求失败时仍会清除本机状态并提示可在其他设备撤销。使用中的会话过期或被撤销时保留修改并提示先导出、退出后重新登录，不自动清空未同步数据。切换账号时只使用当前账号缓存；其他账号的未同步或无法读取的缓存保留，正常已同步缓存可清理。同一浏览器多个页面修改账号缓存时，收到存储变更的页面暂停编辑与后续同步并要求先导出再刷新；不支持多个标签页同时编辑。

### 账号注销

账号弹窗提供独立“注销账号”入口，显示不可恢复的数据范围，输入“注销”二次确认。密码账号必须重新输入当前密码；OAuth 账号需在最近 15 分钟内重新登录。删除包括当前账号的城市足迹、省份标记、会话、媒体对象、同步日志和幂等回执；未同步修改会丢弃，应先导出备份。登录前的本地足迹保留。

服务端先暂停账号，撤销其他会话，再清理 S3 对象，最后删除数据库记录。清理失败暂停编辑并保留重试入口，重新登录也只允许查询账号、退出或重试注销。用户在前端没有收到明确成功结果时不会自动清除账号缓存。成功后清除当前账号缓存和会话；其他账号未同步/损坏缓存保留。

丢失成功响应可用原注销会话在 24 小时内重复确认，返回完成；该回执只保存令牌哈希和过期时间，不保存账号信息或足迹，过期后不可再用，每小时清理过期项。真实 GitHub/Google 授权验收按用户要求留待实际部署后进行。

## 响应式与键盘交互

桌面采用地图与目的地侧栏布局，手机改为上下布局。手机省内地图工具栏提供“选择城市”入口，打开可滚动选择弹窗：支持名称搜索及全部、未打卡、已打卡筛选，可连续点选并实时显示打卡数量，也可从已打卡城市进入编辑。弹窗关闭后地图与列表同步更新。手机侧栏城市列表采用单列，保留完整名称，选择行至少 52px、编辑入口至少 44px，不再使用两列内嵌滚动。足迹弹窗在小屏幕内可滚动，导入导出入口保留在页脚。

地图区域可通过键盘聚焦，按 Enter 或空格进入省份或切换城市标记；表单和弹窗沿用原生控件及 shadcn/Radix 的焦点交互。系统偏好减少动画时关闭页面动画和过渡。

## 验收场景

1. 在全国地图点击浙江，显示 11 个城市；点击杭州无需弹窗即标记去过，自动着色，全国浙江也变为已探索。
2. 连续点击同一省的未标记城市，自动分配使用次数最少的颜色，省份数量只增加一次；再次点击城市取消，“撤销”可恢复原颜色、日期和备注。
3. 点击杭州列表旁的铅笔按钮，修改日期、备注或颜色，记录数量不变；刷新后记录仍在，页面回到全国地图。
4. 独立标记某省，然后记录其城市；取消独立标记后城市仍在，省份仍计入已探索。
5. 删除某省最后一条城市足迹：有独立标记时保留该省探索状态，否则恢复未探索。
6. 搜索城市名称能找到所属省份；进入该省后搜索只匹配本省区域，无匹配时有提示。
7. 导出备份后导入，确认替换才更新数据；取消或导入无效 JSON 时保留原记录。
8. 手机布局没有横向溢出，可一键标记并通过独立按钮编辑；键盘可在省内地图切换标记。
9. 进入浙江后打开“OSM 底图”，可看到杭州湾等海岸线与行政边界吻合；点击杭州或在聚焦后按 Enter 标记，颜色与列表同步；关闭开关后回到原有 SVG 地图且标记保持。

10. 标记杭州后全国城市打卡率为 1 / 391（0.3%），浙江显示 1 / 11（9.1%）；取消和撤销后统计同步变化，单独标记省份不会增加城市打卡率。
11. 在全国和浙江分别打开统计弹窗，生成 PNG，图中地图和统计对应当前范围；手机可预览及保存，无足迹也能生成，图片不包含备注或 OSM 底图。

12. 在桌面及手机打开海南，三亚在放大的本岛主图中可直接标记，三沙在附图中仍可标记，搜索及统计记录保持一致。
13. 手机点击“选择城市”，搜索三亚并连续标记、取消，筛选已打卡可查看记录，点击编辑可修改备注；长县名完整可读，清空搜索及切回全部可恢复列表。

14. 依次在五个尚未探索的省份记录第一座城市或独立标记省份，全国地图使用固定的相邻不同色配色；同一省同时有独立标记和城市足迹只计一次颜色。已有省份添加独立标记或在独立标记后添加首座城市时，全国地图的省份颜色保持不变，取消独立标记保留城市记录。

15. 导入含 30 个已探索省份、城市颜色以绿色为主的旧备份，全国地图使用五色区分省份，有共同边界的已探索省份颜色不同，不要求每种颜色数量相等；刷新后颜色一致，城市原颜色、日期、备注及独立省份标记状态保留。

16. 在桌面和手机全国地图点击北京、天津、香港、澳门快捷按钮，分别进入对应区县地图；键盘 Enter / 空格可执行同样操作。返回全国地图后快捷入口恢复，颜色与地图及探索状态一致，原有足迹数量不变，手机无横向溢出。

17. 把浏览器中 `shanhai-travel-v1` 改成损坏的 JSON、未知版本或含无效记录的内容后刷新：弹出读取失败窗口，原始缓存不变，页面不自动清空；“导出原始数据”能下载原内容；“恢复可识别的记录”按提示数量保留有效记录，“以空数据开始”需二次确认，两者都会留下 `shanhai-travel-v1-unreadable-*` 副本。
18. （配置后端）用户名密码注册并登录：弹窗关闭、提示已登录、头像出现；错误密码显示中文错误且弹窗保留；本机登录前的足迹不出现在登录后的列表里。
19. （配置后端）登录后标记杭州，刷新页面后仍在且无本地足迹闪现；在另一浏览器登录同一账号能看到杭州。
20. （配置后端）停止后端后刷新：有账号缓存仍可标记、编辑、删除、撤销，刷新后修改保留，状态为待同步；后端恢复后触发联网事件或点“重试”，修改写入云端且无重复。没有缓存时不接受离线编辑。
21. （配置后端）退出登录两次确认后回到本地足迹，当前账号缓存和 `shanhai-session-v1` 被清除，`shanhai-travel-v1` 内容不变；其他账号的未同步/损坏缓存保留。使用中的会话在服务端被撤销后请求失败，提示先导出再重新登录，未同步修改保留而不是自动清除。
22. 未配置 `VITE_API_BASE_URL` 时页眉没有登录入口，网络面板没有 `/api` 请求。手机宽度下登录入口可见且页眉无溢出。

23. 两台设备从相同快照分别修改不同城市，重连后自动合并；分别修改同一城市（含编辑/删除）时出现冲突弹窗，选择本机或云端后其他城市保留，初始 revision=0 的并发写入同样受保护。
24. 破坏账号缓存后刷新：原始字符串保持不变，页面不自动覆盖或上传空数据；可导出原始账号缓存。模拟存储空间不足时编辑被拒绝，现有足迹可导出；会话失效时未同步修改不自动丢失。

25. 在北京标记东城区、西城区，全国城市计数仅增加 1，省内进度为 2 / 16，足迹列表保留两条；取消其中一条全国计数不变，取消最后一条才减少 1，撤销可恢复。天津、上海、重庆、香港、澳门使用同样规则；仅独立标记这些省级区域不增加城市数。统计弹窗及全国分享图片使用相同全国口径，省内图片仍显示区县进度。
26. 导入金门县、连江县（马祖）旧台湾足迹，确认后均出现在福建，颜色、日期及备注不变；刷新后仍可编辑、取消及撤销。全国搜索“金门”指向福建，台湾列表不再显示这两项；有独立台湾标记时仍保留台湾探索状态，无独立标记且无其他台湾足迹时不再计入台湾。福建地图岛屿不会同时响应泉州或福州的标记。

23. 探索全部 34 个省份，全国地图所有共同边界两侧颜色不同；取消任意省份探索或导入不同探索范围后，其余省份颜色保持不变。全国目的地列表、快捷入口和分享图片颜色与全国地图一致，城市原有手选颜色不变。

## 当前功能边界

未登录时足迹记录是浏览器本地模式；配置后端后可选登录，足迹保存到云端并在页面可见时同步（见上文“账号与云端同步”）。前端不依赖后端即可完整使用（未配置 `VITE_API_BASE_URL` 时不发送任何后端请求）；后端基础设施见 [后端初始化](backend.md)。尚无本地数据迁移上云（登录期间看不到登录前的本地足迹）、服务端增量变更日志与后台定时同步、账号注销、找回密码、多人共享、照片上传、路线规划或同一城市多次旅行记录。地图边界不是实时更新；OSM 底图是可选的联网功能，离线时不可用，具体数据年份与维护限制见地图说明。

### F1 补齐验收

- 两台设备交错编辑不同城市，批量提交与增量拉取后均保留；同一记录冲突仍由用户选择。
- 批量提交已在服务端生效但响应丢失：刷新后原请求 ID/内容恢复，重放不覆盖更新后的记录；在等待期间发生的新本机编辑也保留。
- 老账号 revision 不为 0 但没有新日志时，自动回退完整快照；旧逐条写入仍兼容，并进入新日志。
- 注销确认未输入或密码错误时不删除；S3 清理失败可重试；注销完成后全部会话失效，其他用户记录不受影响，登录前本地记录仍在。
