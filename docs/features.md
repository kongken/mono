# 功能描述

## 产品与使用流程

山海足迹帮助用户用颜色记录在中国走过的地方。用户在全国地图选择省级区域，进入省内地图，点击城市或区县即可自动配色并标记去过，再次点击取消；需要时另行编辑旅行日期与备注。

当前数据覆盖 34 个省级区域和 497 个城市、自治州、县市或区县。本文中的“城市足迹”统称这些可记录区域；数据范围见 [数据与地图说明](data-and-maps.md)。

## 全国与省内地图

- 初始打开全国地图；点击地图轮廓或目的地列表进入对应省内地图。
- 普通省份展示城市、自治州等下一级区域，直辖市及港澳展示区县，台湾展示县市。
- 全国地图中，存在省份独立标记或任意城市足迹的省级区域都会着色。
- 省内地图只按城市足迹着色；单独标记省份不会把省内全部城市标为去过。
- 全国着色优先使用省份独立标记的颜色；没有独立标记时，使用保存数组中该省第一条城市足迹的颜色。
- 点击省内区域或城市列表主按钮直接切换去过状态，不弹出编辑窗口；键盘 Enter 或空格执行相同切换。
- 已去过的城市列表行显示铅笔编辑入口，打开弹窗回填原记录。
- “中国”面包屑、返回按钮或品牌入口可回到全国地图。切换地图会清空搜索、重置缩放并回到地图标签页。
- 地图支持放大、缩小和重置；当前为以中心缩放，不支持拖动平移。地图加载失败时提供重新加载按钮。
- 省内地图右上角提供“OSM 底图”开关，默认关闭。开启后该省改用 OpenStreetMap 瓦片底图，行政区域叠加在底图上，支持滚轮或按钮缩放及拖动平移；点击、键盘 Enter 或空格切换去过状态的规则不变。全国地图不受影响，始终使用本地绘制。开关偏好保存在当前浏览器，再次进入省内地图时沿用。
- 开启底图后浏览器会向 `tile.openstreetmap.org` 请求瓦片，页面角落显示 OpenStreetMap 署名；底图加载失败时提示可关闭底图，区域标记仍可使用。关闭开关即恢复原有 SVG 地图和中心缩放。

## 省份独立标记

省内页面提供“标记去过此省”和“取消省份标记”。新增独立标记默认为山野绿，适用于只想记录去过该省、尚未补全城市的情况。

独立标记与城市足迹相互独立：取消独立标记会保留城市记录；如果仍有城市足迹，全国地图中的该省仍算已探索。

## 城市足迹

地图和目的地列表支持一键标记与取消。新增足迹自动使用本省现有足迹中使用次数最少的颜色，并默认当天日期和空备注；使用次数相同时按调色板顺序选择，已有城市的颜色保持不变。

取消会移除该城市的足迹，包括日期与备注；提示出现期间可点“撤销”恢复完整记录。撤销入口仅针对最近一次取消，其他操作提示或提示自动消失后不可用。

可从已标记城市旁的铅笔按钮、“添加足迹”、收藏卡片或最近足迹进入编辑弹窗。

| 字段 | 当前规则 |
| --- | --- |
| 省份 | 可从全部省级区域中选择；改变省份会清空城市和备注，重置颜色与日期 |
| 城市 / 区县 | 必须选择，候选项随省份变化 |
| 颜色 | 默认自动选择山野绿、日落黄、珊瑚橙、海岸蓝或暮光紫，可手动调整 |
| 旅行日期 | 新增默认当前浏览器本地日期，可修改或留空 |
| 旅行记忆 | 选填，最多 1000 字符，保存时去除首尾空白 |

每个区域 ID 只保存一条足迹。再次保存已有城市会更新原记录，不会增加足迹数量；目前不能为同一城市记录多次独立旅行。

已有足迹可通过“移除足迹”删除。删除后，该城市恢复未探索状态，收藏和统计同步变化；若该省没有其他城市足迹和独立标记，全国地图中的省份也恢复未探索。

## 搜索与足迹查看

- 全国搜索匹配省份名称或省内城市名称，展示匹配的省份；例如搜索“杭州”会显示浙江。
- 省内搜索匹配当前省份下的区域名称。搜索使用名称包含匹配，暂不支持拼音或模糊纠错。
- 搜索可清空，没有匹配结果时显示提示。
- “旅行足迹”标签页展示城市足迹卡片，按日期降序排列。当前选中省份时，只展示该省足迹。
- “查看全部”清除省份筛选并切换到收藏视图。
- 最近足迹展示全局按日期降序排列的前 4 条记录；空日期排在有日期的记录之后。点击卡片可以编辑。
- 尚无足迹时提供空状态及添加第一站入口。

## 统计口径

| 指标 | 计算方式 |
| --- | --- |
| 已探索省份 | 省份独立标记的 ID 与城市足迹所属省份 ID 的去重并集 |
| 已留下足迹 | 已保存的城市或区县记录数量，不包含独立省份标记 |
| 中国探索度 | 已探索省份数量 / 34，四舍五入为整数百分比 |
| 省内已走过数量 | 当前省份城市足迹的数量 |

## 保存与备份

每次足迹或独立省份标记变化后自动保存到当前浏览器。刷新或重新打开同一网站来源后恢复记录；页面选中的省份、搜索和缩放不会持久化。

导出会下载带有日期的 JSON 备份。导入会校验文件并显示记录数量，用户确认后替换当前全部足迹和独立省份标记；确认前可导出当前数据。无效文件只显示错误提示，不替换记录。文件限制、格式及兼容性见 [数据与地图说明](data-and-maps.md)。

保存失败时显示提示与导出入口。数据暂不跨浏览器或设备同步，清除网站存储会移除本地记录。

## 响应式与键盘交互

桌面采用地图与目的地侧栏布局，手机改为上下布局。足迹弹窗在小屏幕内可滚动，导入导出入口保留在页脚。

地图区域可通过键盘聚焦，按 Enter 或空格进入省份或切换城市标记；表单和弹窗沿用原生控件及 shadcn/Radix 的焦点交互。系统偏好减少动画时关闭页面动画和过渡。

## 验收场景

1. 在全国地图点击浙江，显示 11 个城市；点击杭州无需弹窗即标记去过，自动着色，全国浙江也变为已探索。
2. 连续点击同一省的未标记城市，自动分配使用次数最少的颜色，省份数量只增加一次；再次点击城市取消，“撤销”可恢复原颜色、日期和备注。
3. 点击杭州列表旁的铅笔按钮，修改日期、备注或颜色，记录数量不变；刷新后记录仍在，页面回到全国地图。
4. 独立标记某省，然后记录其城市；取消独立标记后城市仍在，省份仍计入已探索。
5. 删除某省最后一条城市足迹：有独立标记时保留该省探索状态，否则恢复未探索。
6. 搜索城市名称能找到所属省份；进入该省后搜索只匹配本省区域，无匹配时有提示。
7. 导出备份后导入，确认替换才更新数据；取消或导入无效 JSON 时保留原记录。
8. 手机布局没有横向溢出，可一键标记并通过独立按钮编辑；键盘可在省内地图切换标记。
9. 进入浙江后打开“OSM 底图”，可看到杭州湾等海岸线与行政边界吻合；点击杭州或在聚焦后按 Enter 标记，颜色与列表同步；关闭开关后回到原有 SVG 地图且标记保持。

## 当前功能边界

目前是浏览器本地应用，尚无登录、云端同步、多人共享、照片上传、路线规划或同一城市多次旅行记录。地图边界不是实时更新；OSM 底图是可选的联网功能，离线时不可用，具体数据年份与维护限制见地图说明。
