## 维护方式

功能修改与对应文档一起完成。先描述用户可观察到的结果，再写规则和限制；使用“省级区域”“城市足迹”“省份独立标记”等已有术语。

现有文档描述已实现行为。新增文档应在上表登记，尚未实现的功能应明确标为待实现。区域数量以地图检查脚本和当前数据为准。
