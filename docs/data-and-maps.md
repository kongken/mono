# 数据与地图说明

## 足迹数据结构

存储键为 `shanhai-travel-v1`，当前结构版本为 `1`。本地存储与导出备份使用同一结构。

```json
{
  "version": 1,
  "visits": [
    {
      "code": "330100",
      "name": "杭州市",
      "province": "330000",
      "color": "#719fc6",
      "date": "2026-10-12",
      "note": "西湖漫步"
    }
  ],
  "provinces": {
    "330000": "#4b937d"
  }
}
```

| 字段 | 含义与约定 |
| --- | --- |
| `version` | 数据结构版本，当前只接受 `1` |
| `visits` | 城市足迹数组，每个 `code` 唯一 |
| `code` | 城市或区县 ID，以字符串保存 |
| `name` | 当前区域索引中的显示名称 |
| `province` | 所属省级区域 ID，以字符串保存 |
| `color` | 五种足迹色彩之一 |
| `date` | `YYYY-MM-DD` 格式字符串，或空字符串 |
| `note` | 备注字符串，最大 1000 字符 |
| `provinces` | 省份独立标记，键为省级区域 ID，值为颜色 |

颜色映射为：山野绿 `#4b937d`、日落黄 `#e2af5c`、珊瑚橙 `#d88370`、海岸蓝 `#719fc6`、暮光紫 `#a08cbd`。

新探索省份的独立标记或第一条城市足迹，按全国已探索省份的记录代表色选择使用次数最少的颜色（每省计一次，独立标记颜色优先）；已有记录代表色时沿用。后续城市足迹选择本省现有城市足迹中使用次数最少的颜色。使用次数相同时按上述颜色顺序选择；新记录仍保存具体颜色值，数据版本保持为 `1`，既有手选颜色不重新计算。

业务行为见 [功能描述](features.md)。保存城市会先移除原 ID 的记录，再追加新记录，因此更新可能改变数组顺序；记录代表色优先取独立省份标记的保存颜色，否则取该数组中第一条所属城市记录，用于新记录的颜色分配。全国地图显示颜色另由已探索省份 ID 的去重并集排序后循环分配五种调色板颜色，列表与全国分享图片沿用同一映射；不写回存储，不依赖城市记录顺序或旧备份中的颜色，数据版本和导入校验不变。

## 本地存储与兼容性

- 启动时读取并校验本地 JSON（逻辑在 `src/lib/persistence.ts`），足迹变化后重新写入完整数据。
- 存储按浏览器和网站来源隔离，协议、主机或端口不同会使用不同存储；开发预览与正式站点不会自动共享记录。
- 后端 PostgreSQL/Redis/S3 基础设施已初始化，详见 [后端初始化](backend.md)；前端尚未接入服务端足迹存储、跨设备同步或结构版本迁移。
- 读取失败（JSON 无法解析、版本不是 1、记录未通过校验）时保留原始缓存字符串，暂停自动保存，由用户选择导出原始数据、恢复可识别的记录或以空数据开始；后两者先把原始数据复制到 `shanhai-travel-v1-unreadable-<时间戳>`。缓存不存在或为空属于正常首次使用。这些副本不会自动清理，也不会被应用读取。
- 修改版本、名称或区域 ID 前仍需设计兼容或迁移路径，保留已有足迹；区域索引更新会使旧缓存校验失败并进入上述保护流程，而不是被清空。
- 写入失败会显示保存异常提示，内存中的记录仍可导出；页面关闭后不能保证保留未写入数据。

## 备份导入导出

导出文件名为 `山海足迹-YYYY-MM-DD.json`。日期来自浏览器本地时间，文件内容为完整足迹数据。

导入最多接受 2,000,000 字节的文件，先解析和校验，再显示替换确认弹窗。确认后整体替换数据，不做合并；确认前提供导出当前备份入口。

当前校验包括结构版本、足迹数组、省份标记对象、城市与所属省份及名称的一致性、重复城市 ID、允许的颜色、日期字符串格式和备注长度。日期校验为格式检查，尚未额外验证实际日历日期。校验依赖当前 `src/regions.json`，区域索引更新可能影响旧备份兼容性。

## 地图文件与区域索引

| 文件 | 职责 |
| --- | --- |
| `public/maps/100000.json` | 全国省级边界及南海附图数据 |
| `public/maps/<省级区域ID>.json` | 对应省内行政区域边界 |
| `src/regions.json` | 省份 ID、全称、简称及下级区域 ID/名称，用于列表、搜索和备份校验 |
| `src/lib/maps.ts` | GeoJSON 多边形方向归一化，适配 d3 的球面绘制 |
| `src/lib/tiles.ts` | 解析瓦片源环境变量并提供默认值 |
| `src/lib/coords.ts` | GCJ-02 与 WGS-84 坐标转换，用于把边界叠加到 OSM 底图 |
| `src/components/OsmProvinceMap.tsx` | 省内可选 OSM 底图（Leaflet），按需加载 |
| `scripts/download-maps.mjs` | 根据现有全国地图下载省内地图并重建索引 |
| `scripts/prepare-taiwan.mjs` | 处理台湾补充数据的名称、ID、中心点及多边形方向 |
| `scripts/check-maps.mjs` | 校验全国覆盖、省内索引一致性、ID 唯一性、多边形方向及投影路径 |

当前共有 34 个省级区域和 497 个可记录下级区域。数量是当前数据快照；更新后以 `npm run check:maps` 的实际结果为准。

普通区域 ID 来自数据中的 `adcode`，应用统一转换为字符串；台湾补充区域使用 `tw-<county_id>`，例如台北市为 `tw-63000`，避免与其他区域 ID 冲突。

## 来源与边界限制

全国及除台湾外的省内数据来自 [阿里云 DataV GeoAtlas](https://datav.aliyun.com/portal/school/atlas/area_selector)，省内下载接口为 `https://geo.datav.aliyun.com/areas_v3/bound/<adcode>_full.json`。

台湾县市边界来自 [ronnywang/twgeojson](https://github.com/ronnywang/twgeojson) 的 `twcounty2010.2.json`。其源数据为 2012 年县市边界；处理脚本将部分名称转换为简体，并把桃园县显示为桃园市，未据此重绘边界。

直辖市和港澳提供区县数据，而不是常规省份的地级市数据。地图用于旅行可视化，下载快照可能与最新行政区划不同。

## OSM 底图（可选）

省内地图可通过开关改用 [OpenStreetMap](https://www.openstreetmap.org/copyright) 瓦片（`https://tile.openstreetmap.org/{z}/{x}/{y}.png`）作为底图，使用 Leaflet 绘制，并在首次开启时按需加载。偏好保存在独立存储键 `shanhai-basemap-v1`（`osm` 或 `off`），不属于足迹数据，也不进入导出备份。

- 默认关闭，关闭时不发起任何第三方地图请求，仍满足“运行时无需第三方地图请求或 API Key”；开启后才会请求瓦片，无需 API Key。
- DataV 边界为 GCJ-02 坐标，而 OSM 使用 WGS-84。开启底图时对除台湾（`tw-` 补充数据）、香港、澳门以外的区域做 GCJ-02 到 WGS-84 的近似转换；转换仅用于底图视图，`public/maps` 数据与区域 ID 不变，SVG 视图仍使用原坐标。
- 瓦片通过 CSS 滤镜降低饱和度与对比度，使叠加的区域颜色和标签更清晰。评估过 Carto Positron 公共瓦片，目前需要 API Key，不可直接使用；更浅的底图建议改用自托管瓦片。
- 瓦片源可在构建时通过环境变量配置，未设置或格式无效时回落到上述 OSM 公共瓦片：`VITE_OSM_TILE_URL`（必须包含 `{z}`、`{x}`、`{y}`）、`VITE_OSM_TILE_MAX_ZOOM`（1–22 的整数；自定义地址默认 18，默认地址为 19）、`VITE_OSM_TILE_ATTRIBUTION`（附加署名，作为 HTML 显示，仅用于受信任的构建配置；OpenStreetMap 署名始终保留）。变量在构建时写入，修改后需重新构建；Docker 镜像通过 `--build-arg` 传入，当前 CI 工作流尚未传递这些参数。源码见 `src/lib/tiles.ts`。
- 全国地图使用圆锥投影，且包含南海附图，不使用 OSM 底图。
- 当前限制：开发阶段直接使用 OSM 公共瓦片，其[使用政策](https://operations.osmfoundation.org/policies/tiles/)不适合大流量生产场景，正式上线前需改为自托管瓦片或商业服务；香港、澳门边界未做坐标转换，台湾边界精度以数据源为准；边界与底图的行政区域线可能存在差异和偏移。

## 绘制与维护

浏览器从部署站点读取本地地图资源，通过 Vite 的 `BASE_URL` 拼接路径。运行时无需请求供应方接口或配置地图 API Key。

全国地图使用圆锥正形投影，省内使用墨卡托投影。全国相机范围按主体边界计算，南海相关附图单独绘制。海南省内 SVG 主图的缩放范围使用除三沙之外的本岛区域，三沙原始边界使用独立墨卡托投影绘制为附图（分享图片沿用此布局）；OSM 初始及重置视野也使用本岛边界，完整三沙图层仍保留。此调整不修改 GeoJSON、区域 ID 或足迹数据。数据先通过 `normalizeMap` 修正多边形方向，避免被 d3 解释为地球另一侧的大面积区域。

更新省内地图时运行 `npm run download:maps`，完成后运行 `npm run check:maps` 与 `npm run build`，再检查受影响区域的可视效果及旧足迹兼容性。下载脚本依赖现有全国文件，当前不会自动刷新 `100000.json`；更新全国数据需单独替换该文件，再重建省内数据与索引。

下载失败可能留下部分已更新地图，需检查地图与索引一致性后再交付。地图文件、区域索引、来源说明和受影响的数量描述应在同一次变更中同步更新。
